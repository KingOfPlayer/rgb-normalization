# Cosine Similarity Component

## Overview
The **Cosine Similarity** package is a custom NovaVision component designed to calculate the semantic similarity between two embedding vectors. It processes two 1D float arrays (such as those generated by Embedding Extraction nodes) and returns a similarity score between `-1.0` and `1.0`.

This component is optimized for the NovaVision runtime and uses `numpy` for efficient mathematical operations.

## Features
- **Plug-and-Play Integration:** Seamlessly connects with NovaVision `EmbeddingExtraction` nodes (both Text and Image).
- **Data Validation:** Utilizes Pydantic to strictly validate that input arrays are non-empty and correctly formatted before execution.
- **Robust Import Fallbacks:** Includes resilient import logic that supports both the platform's isolated build/update phases and the standard execution runtime.
- **High Performance:** Computes similarity scores instantly using pure NumPy vector algebra.

## Inputs and Outputs
### Inputs
- `embedding1` (List[float]): The first embedding vector (e.g., extracted from an image).
- `embedding2` (List[float]): The second embedding vector (e.g., extracted from text).

### Outputs
- `similarity` (float): A scalar value indicating the cosine similarity between the two vectors. 
  - `1.0` = Perfect similarity (identical direction)
  - `0.0` = Orthogonal (no correlation)
  - `-1.0` = Perfect dissimilarity (opposite direction)

## Usage in NovaVision
1. Ensure the package is installed in your NovaVision Workspace.
2. Drag and drop the **CosineSimilarity** component into your flow canvas.
3. Connect the output of an `EmbeddingExtraction` node (e.g., processing an Image) to the `embedding1` cable input.
4. Connect the output of a second `EmbeddingExtraction` node (e.g., processing Text) to the `embedding2` cable input.
5. Click **Run Flow**. The component will automatically calculate and output the semantic similarity score between the two entities.

## Mathematical Logic
The package calculates cosine similarity using the standard formula:
```math
\text{similarity} = \frac{\mathbf{A} \cdot \mathbf{B}}{\|\mathbf{A}\| \|\mathbf{B}\|}
```
This is implemented safely using `numpy.dot` and `numpy.linalg.norm`. If any vector is a zero vector, the script elegantly catches `DivisionByZero` risks and defaults to returning `0.0`.
